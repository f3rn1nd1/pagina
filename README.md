# Portafolio de Yomara Bernal

Proyecto Astro basado en CV_Yomara_Bernal_actualizado.docx. Los gráficos de proyectos son representaciones conceptuales, sin capturas ni datos internos. No se incluyen documentos de identidad ni dirección particular.

## Uso

Desde esta carpeta:

- npm.cmd install
- npm.cmd run dev
- Abrir http://localhost:4321
- npm.cmd run build para generar dist/
- npm.cmd run preview para revisar la compilación

El contenido y los estilos están en src/pages/index.astro. El CV señala formación en curso durante 2020–2025; confirmar la situación académica actual antes de publicar. Los enlaces de contacto abren el cliente de correo.
